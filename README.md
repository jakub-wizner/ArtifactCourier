# Artifact Courier

A single-player, top-down driving and combat game set across seven stylized cities. Collect artifacts, deliver them to matching recipients, and survive the journey. Complete each city's delivery quota to advance; Buenos Aires and Cairo also require defeating a boss.

## Driving and controls

Driving uses acceleration, momentum and steering. Attack while moving, use nitro on open roads, and handbrake into tighter turns.

| Key | Action |
| --- | --- |
| WASD / arrows | Accelerate, reverse and steer |
| Shift / Ctrl | Nitro / handbrake drift |
| Space | Basic attack |
| Q / E | Special from level 3 / finisher from level 5 |
| F | Release a fully charged resonance ability |
| R | Dash after purchasing Mobility |
| G / M / Esc | Vehicle shop / map / pause |

## Player classes

- **Nightjar motorcycle:** fastest, light armor, quick short-range slashes.
- **Bison pickup:** slowest, toughest, heavy 360-degree slam.
- **Kestrel standard car:** balanced handling and health, radial pulse, later EMP and ranged attacks.

## Bonuses and progression

Collect repairs, shields, speed boosts, cargo expansion, attack boosts, temporary invulnerability and cooldown reductions. Road coins buy class-specific appearance kits with different capabilities, unlocked at levels **2, 4 and 6**. First city clears award skill points for Mobility, Combat or Courier upgrades.

## Enemies and scoring

Police intercept, robbers steal cargo, jammers slow you, racers charge, tow trucks pull you, and oil droppers leave hazards. Boss attacks have warning areas: move before they strike.

Deliveries, drifting, clean passes, coins and driving challenges earn style points. Follow optional radio beacons to charge resonance. End screens show your final score; retrying a failed city resets its attempt score while keeping saved upgrades.

## Run the project

Open with **Unity 6000.3.23f1**.
